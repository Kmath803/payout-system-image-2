
# Payout System Dashboard

A web page for displaying the Payout System
Technical Control Console image.

## Files

- `index.html` — Displays the dashboard image.
- `payout-dashboard.jpg` — The dashboard image.

## Website

https://kmath803.github.io/payout-system-image-2/

## Important Notice

This project displays an image only. It does not
process payments, verify transactions, or connect
to a real payment gateway.
